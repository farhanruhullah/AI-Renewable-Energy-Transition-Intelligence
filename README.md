# 🌍 AI Renewable Energy Transition Intelligence

## Overview

AI-powered energy transition analytics and decision-support platform using Machine Learning, Explainable AI (SHAP), Energy Transition Readiness Index (ETRI), and scenario simulation.

## Features

- Global and country-level energy analysis
- CO₂ emissions per capita prediction
- SHAP-based explainable AI
- Energy Transition Readiness Index (ETRI)
- Renewable energy scenario simulation
- Dynamic policy decision support

## Machine Learning Pipeline

Energy Data
↓
Feature Engineering
↓
Random Forest Regression
↓
CO₂ Prediction
↓
SHAP Explanation
↓
ETRI Assessment
↓
Scenario Simulation
↓
Policy Support

## Technologies

- Python
- Streamlit
- Scikit-learn
- Random Forest Regression
- SHAP
- Plotly
- Pandas

```bash
pip install -r requirements.txt
streamlit run app.py
```
